# İngilizce katman, biçim

Türkçe kaynak dosyalara dokunulmaz. İngilizce metinler ayrı dosyalarda `addEn({...})` ile eklenir. Motor `linux-lab/i18n-core.js`.
Dil `LAB_LANG` değişkeni, `shell.js` içinde tanımlı, app.js profil ayarından atar. Shell ve eklenti mesajları `lt('türkçe', 'english')` ile iki dilli yazılır.

```js
'use strict';
addEn({
  chapters: {
    nav: { title: 'Navigation', sub: 'Find your way around the filesystem' },
  },
  missions: {
    nav3: {
      title: 'Hidden file hunt',
      story: '...', task: '...', hint: '...',
      v: [ { story: '...', task: '...', hint: '...' }, { title: '...', story: '...', task: '...', hint: '...' } ],
    },
  },
  quiz: {
    'Türkçe soru metni, QUIZ içindeki q ile birebir aynı': { q: 'English question', a: ['correct first', 'b', 'c', 'd'] },
  },
  badges: { sysadmin: { title: 'Sysadmin', desc: '...' } },
  x: {
    cut: {
      d: 'Cuts selected fields or characters from each line',
      o: { '-d': 'Field delimiter ...', '-f': { t: 'Fields to select ...', a: 'fields' } },
      ex: ['Lists user names', 'Second and fourth CSV column'],
      tip: '...',
      pos: ['file...'],
      sub: { log: { d: '...', o: {}, ex: [] } },
    },
  },
});
```

Kurallar
- missions anahtarı görev id. `v` dizisi görevin variants dizisiyle aynı sırada ve aynı uzunlukta. Bir varyant Türkçede hangi metin alanını tanımlıyorsa İngilizcesi de o alanı tanımlar.
- quiz anahtarı Türkçe soru metninin kendisi, `a` şıkları Türkçe sırayla aynı, ilk şık doğru cevap.
- x anahtarı komut adı. `o` içinde her seçenek için açıklama metni ya da `{t, a}`, `ex` örnek açıklamaları aynı sırayla, sadece açıklama metni, komutun kendisi değil. `sub` alt komutlar aynı biçimde. `bsd`, `kv`, `v` gibi değer haritaları da aynı anahtarlarla.
- İngilizce doğal, kısa ve teknik olarak doğru. Hikaye ve isimler aynı kalır, Burak, Ayşe, IST-BR-07 gibi. Komutlar, dosya yolları, çıktı ve submit cevapları asla çevrilmez, ters tırnaklar korunur.
- Yazım kuralı İngilizcede de geçerli. Em dash, en dash, parantez, iki nokta ve ** yok. Türkçe karakter yok, özel isimler hariç.
- Kontrol `node tests/i18n.test.js` ve NetDevOps için `node tests/i18n.test.js netdevops`.
